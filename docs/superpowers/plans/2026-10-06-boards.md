# Boards Implementation Plan

> Executed inline in the session (superpowers:executing-plans), never with a
> subagent per task. Steps use checkbox syntax.

**Goal:** a `board` list type for Obsidian Kanban files, with dates, card moves
and Omarchy reminders.

**Architecture:** the Python helper owns the file format, the actions and the
reminders (state file plus a lock, so one bar per screen sends once). The
model orders lanes and labels dates. QML shows layout A.

**Tech stack:** Python 3 standard library, Quickshell QML, node --test.

**Spec:** `docs/superpowers/specs/2026-10-06-boards-design.md`

## Global Constraints

- Python standard library only; every write re-reads the file and matches
  the card by its key; `changed` when it is gone.
- Never touch the file after `***` or `%% kanban:settings`.
- QML files stay at 300 lines or fewer; colors from `Color`, durations through
  `Style.duration`; no em dashes anywhere.
- No live install, shell restart or config change while the user is away.

## Review Focus

1. A card with indented lines: moves, removes and clears take the whole block.
2. Two cards with the same text: keys `text` and `text #2` stay distinct.
3. A board with the settings block and an archive: bytes after them unchanged.
4. Two bars run `remind` at once: one notification.
5. A board without a Complete lane: tick marks `[x]` in place.

## Tasks

### Task 1: parse and read a board
- Files: `helper/shelf_board.py`, `tests/test_board.py`
- Produces: `parse_board(lines) -> dict` with `lanes: [{title, line, complete,
  cards: [{key, text, date, time, checked, start, end}]}]`, `end` (first line
  not read), `triggers`, `dateFormat`; `read_board(vault, cfg) -> payload`
  with `lanes: [{title, complete, items: [{key, text, date, time, checked}]}]`.
- Tests: lanes and titles (limit suffix stripped), Complete lane, card
  continuation lines, keys with `#2`, dates and times, custom triggers,
  other date format, stop at `***` and at the settings block, missing file.

### Task 2: board actions and CLI
- Files: `helper/shelf_board.py`, `helper/shelf_cli.py`, tests.
- Produces: `add_board(vault, cfg, lane, text)`, `move_board(vault, cfg, key,
  lane)`, `done_board`, `date_board(vault, cfg, key, date, time, today)`,
  `edit_board`, `remove_board`, `clear_board`; CLI verbs `move --lane`,
  `date --date --time`, and `add/done/edit/remove/clear` for boards.
- Tests: each row of spec section 3, block moves, `changed`, bytes after the
  board unchanged, no Complete lane.

### Task 3: seen keys and counts for lanes
- Files: `helper/shelf_seen.py`, `Model.js`, tests.
- `list_keys` and `listKeys` read `lanes`; `listItemCount` counts the cards of
  open lanes.

### Task 4: reminders
- Files: `helper/shelf_reminders.py`, `helper/shelf_cli.py`,
  `tests/test_reminders.py`.
- Produces: `due(payloads, lists, state, now, summary_time) -> (messages,
  state)`, `run(...)` with the lock and the sender; CLI `remind --vault
  --lists [--summary-time]`.
- Tests: timed card rings once; missed rings later the same day, not the
  next day; summary once a day after the time, with today and late cards;
  nothing due sends nothing; `remind: false` and Complete lanes are quiet;
  other date format is quiet; sender falls back to notify-send.

### Task 5: settings helper
- Files: `helper/shelf_settings.py`, tests.
- `scan` suggests boards (and not as checklists); `create_list` writes the
  board skeleton with `**Complete**` under the last lane.

### Task 6: model
- Files: `Model.js`, `tests/model.test.js`.
- Produces: `boardView(listPayload, todayIso)`, `dateLabel(card, todayIso)`,
  `lateCount(payload, lists, todayIso)`, `addTargets(cfg, listPayload)`,
  board copy in `phoneHowTo`, `listDetail`, `trashLabel`.

### Task 7: board tab QML
- Files: `BoardList.qml`, `BoardLane.qml`, `CardRow.qml`, `DatePanel.qml`,
  `DateChip.qml`, `ShelfPopup.qml`, `AddBar` wiring, `tests/qml-source-test.sh`.

### Task 8: service, keys and chip
- Files: `Service.qml`, `Panel.qml`, `ShelfChip.qml`.
- `act` gains `move` and `date`; a 60 s `remind` timer; Shift+Left/Right and
  `t`; the chip count turns urgent with a late card.

### Task 9: settings UI and docs
- Files: `AddListSheet.qml`, `ListRowBody.qml`, `manifest.json`, `README.md`.
- The board kind, the Remind me toggle, `reminderTime` in the schema, README.
